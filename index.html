지금 보이는 숫자와 업체는 예시입니다. 예식일을 바꾸면 체크리스트 기한도 함께 바뀝니다.
지금은 이 기기에만 저장돼요. 연결하면 두 분이 같은 내용을 바로 함께 볼 수 있어요.
입력한 내용은 이 브라우저에 저장되고, 연동하면 두 분이 함께 봅니다.

두 분이 같은 데이터 쓰기

Firebase(구글의 무료 저장 서비스)에 저장하면 한 분이 고친 내용이 상대방 화면에 바로 나타납니다. 대시보드를 여는 사람은 로그인이 필요 없습니다. 처음 만드는 한 분만 아래 설정을 한 번 하면 됩니다.

처음 만드는 사람

  1. Firebase 콘솔에서 프로젝트 추가를 누릅니다. 이름은 아무거나, Google 애널리틱스는 꺼도 됩니다.
  2. 왼쪽 메뉴 빌드 → Firestore Database → 데이터베이스 만들기. 위치는 asia-northeast3 (서울), 모드는 프로덕션 모드를 고릅니다.
  3. 왼쪽 위 톱니바퀴 프로젝트 설정 → 내 앱 → 웹 앱 추가(</>). 앱 이름을 쓰고 등록하면 나오는 firebaseConfig 부분을 복사해서 아래에 붙여 넣습니다.
  1. Firestore Database의 규칙 탭에서 기존 내용을 모두 지우고 아래 규칙을 붙여 넣은 뒤 게시를 누릅니다.

상대방이 보내 준 연결 코드를 붙여 넣으세요.

연결 코드를 아는 사람은 누구나 데이터를 읽고 고칠 수 있습니다. 두 분 외에는 공유하지 마세요.

Firebase와 연결되어 있습니다. 한 분이 고치면 상대방 화면에 바로 나타납니다. 인터넷이 끊겨도 입력할 수 있고, 연결되면 자동으로 저장됩니다.

링크를 열면 따로 설정하지 않아도 자동으로 연결돼요.
