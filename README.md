# comfortsoul

지수와 성수의 결혼준비 대시보드 (`index.html`, 브라우저에서 바로 열기)

## 두 사람이 같은 데이터 쓰기 (구글 시트)

입력값은 기본적으로 쓰는 브라우저에만 저장됩니다. 구글 시트에 저장하면 두 분이 같은 데이터를 봅니다.
대시보드를 여는 사람은 구글 로그인이 필요 없고, 시트를 만드는 한 사람만 처음에 한 번 설정합니다.

1. [sheets.new](https://sheets.new)로 새 시트를 만듭니다.
2. 메뉴 **확장 프로그램 → Apps Script**에서 기존 코드를 지우고 대시보드의 코드를 붙여 넣은 뒤 저장합니다.
   (대시보드의 **저장: 이 브라우저** 버튼 → "붙여 넣을 코드 보기" → "코드 복사")
3. **배포 → 새 배포 → 웹 앱**. 실행 사용자 **나**, 액세스 **모든 사용자**로 배포하고 권한을 승인합니다.
4. 나온 웹 앱 URL(`…/exec`)을 대시보드의 같은 창에 붙여 넣고 **연결**합니다. 상대방도 같은 URL을 붙여 넣습니다.

- 고친 내용은 1~2초 뒤 시트에 저장되고, 다른 기기의 변경은 30초마다(또는 창으로 돌아올 때) 확인합니다.
- 두 사람이 같은 순간에 고치면 "시트 내용 불러오기 / 내 내용으로 덮어쓰기" 중에서 고르는 안내가 뜹니다.
- 시트의 체크리스트·예산·하객·업체·요약 탭은 보기용입니다. 시트에서 직접 고쳐도 대시보드에 반영되지 않습니다. 실제 데이터는 숨김 탭 `_state`에 있습니다.
- **웹 앱 URL을 아는 사람은 누구나 데이터를 읽고 고칠 수 있습니다.** 레포나 채팅방 등 공개된 곳에 올리지 마세요. URL은 각자 브라우저에만 저장되고 코드에는 들어 있지 않습니다.
- 스크립트를 고친 뒤에는 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영됩니다.

## 시세 데이터 갱신

예산 옆의 참고 시세와 "시세 참고" 카드는 `wedding_data` SQLite DB에서 뽑은 집계값입니다.
DB가 바뀌면 아래 명령으로 `index.html` 안의 데이터를 다시 넣습니다.

```
python3 tools/build_market.py path/to/wedding_data_clean.db
```

DB 원본(업체 연락처, 후기 작성자 등)은 레포에 올리지 않고 집계값과 출처만 페이지에 들어갑니다.
