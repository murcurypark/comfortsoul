# comfortsoul

지수와 성수의 결혼준비 대시보드 (`index.html`, 브라우저에서 바로 열기 / GitHub Pages)

## 화면 구성

태블릿을 기준으로 만들었고 폰에서도 같은 기능을 씁니다. 모든 화면에서 본문 글자는 14px 이상, 누르는 칸은 44px 이상입니다.

| 화면 | 탭 위치 | 배치 |
|---|---|---|
| 폰 (~599px) | 아래 탭 바 | 한 열 |
| 태블릿 세로 (600~899px) | 위쪽 탭 | 한 열, 요약 타일 4칸 |
| 태블릿 가로·큰 화면 (900px~) | 왼쪽 사이드바 | 종합은 2열(1500px~는 3열), 할 일은 체크리스트 + 지금 챙길 일 |

- **종합**: 요약, 지금 챙길 일, 체크리스트, 예산, 하객, 업체를 한 화면에서 보고 바로 고칠 수 있습니다.
- **할 일 / 예산 / 하객·업체 / 시세**: 한 가지씩 크게 보고 고칩니다. 종합과 탭은 같은 데이터를 고치므로 어디서 고쳐도 같이 바뀝니다.
- 글자를 누르면 고칠 수 있고, 삭제하면 "되돌리기"가 나옵니다. 열려 있는 탭은 주소(`#budget` 등)에 남습니다.

## 두 사람이 같은 데이터 쓰기 (Firebase)

입력값은 기본적으로 쓰는 브라우저에만 저장됩니다. Firebase(Firestore, 무료 요금제)에 저장하면
한 분이 고친 내용이 상대방 화면에 바로 나타납니다. 대시보드를 여는 사람은 로그인이 필요 없고,
처음 만드는 한 사람만 아래 설정을 한 번 합니다. 대시보드 상단의 **"저장: 이 브라우저"** 버튼에서 같은 안내를 볼 수 있습니다.

**처음 만드는 사람**
1. [Firebase 콘솔](https://console.firebase.google.com/)에서 프로젝트를 추가합니다.
2. **빌드 → Firestore Database → 데이터베이스 만들기** (위치 `asia-northeast3` 서울, 프로덕션 모드).
3. **프로젝트 설정 → 내 앱 → 웹 앱 추가**에서 나오는 `firebaseConfig`를 대시보드 설정 창에 붙여 넣고 "보안 규칙 만들기"를 누릅니다.
4. 설정 창에 나온 규칙을 Firestore Database의 **규칙** 탭에 붙여 넣고 **게시**합니다.
5. "규칙을 게시했어요. 연결"을 누릅니다. 연결되면 나오는 **연결 코드**(`WED1.…`)를 상대방에게 보냅니다.

**상대방이 연결하는 방법 (가장 쉬운 순서)**
1. **초대 링크**: 연결된 뒤 설정 창에 나오는 "초대 링크"를 보냅니다. 상대방이 링크를 열기만 하면 설정 없이 자동으로 연결됩니다. (웹 주소로 열었을 때만 만들어집니다. 파일로 연 경우에는 아래 연결 코드를 보내세요.)
2. **연결 코드**: 설정 창의 "연결 코드를 받은 사람"에 `WED1.…` 코드를 붙여 넣습니다.

아직 손대지 않은 예시 데이터만 있는 기기가 연결하면 묻지 않고 저장된 내용을 바로 불러옵니다. 이미 직접 입력한 내용이 있는 기기는
"저장된 내용 불러오기 / 내 내용으로 덮어쓰기" 중에서 고르게 합니다.

**처음 열었을 때**: 연결이 안 되어 있으면 연결 설정 창이 한 번 자동으로 열리고, 연결할 때까지 위쪽에 안내 바가 보입니다("나중에"를 누르면 7일간 숨김).

### 처음부터 연결된 상태로 배포하기 (선택)

연결 코드를 페이지에 넣어 두면, 누가 열어도 처음 여는 순간부터 그 방에 저장됩니다.

```
python3 tools/set_default_firebase.py WED1.xxxxx     # 기본 연결 설정
python3 tools/set_default_firebase.py --clear        # 제거
```

**주의: 연결 코드가 index.html 안에 들어가므로 이 페이지의 소스를 볼 수 있는 사람은 누구나 데이터를 읽고 고칠 수 있습니다.**
공개 레포나 누구나 열 수 있는 주소에는 넣지 말고, 두 분만 접근하는 곳에서만 쓰세요. 공개 주소로 쓰려면 비워 두고 초대 링크로 각자 연결하는 방식을 권합니다.

- 항목마다 따로 저장되어서, 두 사람이 서로 다른 항목(또는 같은 항목의 다른 칸)을 동시에 고쳐도 둘 다 남습니다.
- 인터넷이 끊겨도 입력할 수 있고, 연결되면 자동으로 저장됩니다.
- 데이터는 `weddings/{방 코드}/…` 아래에 저장됩니다. 방 코드는 설정 때 무작위로 만들어지고(24자), 보안 규칙에 그 방만 열려 있습니다.
  **연결 코드를 아는 사람은 누구나 데이터를 읽고 고칠 수 있으니** 두 분 외에는 공유하지 마세요.
- 연결 정보는 각자 브라우저에만 저장되며 레포에는 들어 있지 않습니다.

### 테스트

실제 Firebase SDK와 Firestore 에뮬레이터(보안 규칙 포함)로 검증했습니다. 에뮬레이터는 Java가 필요합니다.

## 배포 (Firebase Hosting)

`firebase.json`과 `.firebaserc`가 들어 있어서 같은 Firebase 프로젝트(`jisu-seongsu-wedding`)에 바로 올릴 수 있습니다. 올라가는 파일은 `index.html` 하나입니다.
주소는 `https://jisu-seongsu-wedding.web.app` 입니다. 레포가 비공개여도 상관없고, 무료 요금제 안에서 충분합니다.

1. Firebase 콘솔 → **빌드 → Hosting → 시작하기**를 한 번 눌러 둡니다 (안내 화면은 끝까지 눌러 넘기면 됩니다).
2. 내 컴퓨터에서 (Node.js 필요) 레포 폴더로 들어가 아래를 실행합니다.
   ```
   npm install -g firebase-tools
   firebase login
   firebase deploy --only hosting
   ```
3. 앞으로 고칠 때마다 `firebase deploy --only hosting`만 다시 실행하면 됩니다.

푸시할 때마다 자동으로 올리려면 레포 폴더에서 `firebase init hosting:github`을 한 번 실행하세요. GitHub 연결과 배포용 비밀값 등록, 워크플로 파일 생성을 안내에 따라 해 줍니다. 비공개 레포에서도 동작합니다.

- 배포된 페이지는 **주소를 아는 누구나 열 수 있습니다.** 레포를 비공개로 해도 배포된 페이지의 소스는 공개됩니다. 그래서 방 코드가 든 연결 코드를 페이지에 넣지 말고(`tools/set_default_firebase.py`는 비공개 호스팅용), 초대 링크로 연결하세요.
- 선택: Google Cloud 콘솔 → API 및 서비스 → 사용자 인증 정보에서 이 프로젝트의 브라우저 키에 **HTTP 리퍼러 제한**으로 `jisu-seongsu-wedding.web.app/*`를 걸면, 다른 사이트에서 이 키를 쓰는 것을 막을 수 있습니다. (파일로 열어 쓰는 경우에는 걸지 마세요.)
- GitHub Pages는 무료 플랜에서 비공개 레포로는 쓸 수 없으므로, 레포를 비공개로 바꾸면 Pages 주소는 닫힙니다.

## 시세 데이터 갱신

예산 옆의 참고 시세와 "시세 참고" 카드는 `wedding_data` SQLite DB에서 뽑은 집계값입니다.
DB가 바뀌면 아래 명령으로 `index.html` 안의 데이터를 다시 넣습니다.

```
python3 tools/build_market.py path/to/wedding_data_clean.db
```

DB 원본(업체 연락처, 후기 작성자 등)은 레포에 올리지 않고 집계값과 출처만 페이지에 들어갑니다.
